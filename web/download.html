설치 방법

  1. 받은 HtUtil.Agent.exe 실행 (.NET 설치 불필요)
  2. Windows가 "PC 보호" 경고를 띄우면 추가 정보 → 실행
  3. "이 앱이 디바이스를 변경하도록 허용하시겠어요?"(관리자 권한) 창에서 예 → 서비스로 설치되어 잠금화면·로그인 화면에서도 원격 가능, 재부팅 후 자동 실행
    (아니요를 누르면 일반 모드로 실행 — 잠금화면에서는 원격 불가)
  4. 방화벽 허용 창이 뜨면 허용
  5. 작업 표시줄 트레이에 파란 아이콘이 생기면 완료 (PC는 자동 등록, 이후 업데이트도 자동). 받은 exe 파일은 지워도 됩니다.
